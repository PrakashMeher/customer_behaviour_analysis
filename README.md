# customer_behaviour_analysis
Overview

This project analyzes customer shopping behavior using transactional data from 3,900 customer purchases across multiple product categories.

The project covers the complete data analytics workflow, from data loading and cleaning in Python to SQL-based business analysis, Power BI dashboard development, reporting, and presentation.

Project Objectives:-
Understand customer purchasing patterns
Analyze revenue and spending behavior
Identify high-value and repeat customers
Analyze product and category performance
Compare subscribers and non-subscribers
Understand discount usage and its impact
Create an interactive Power BI dashboard
Present business insights through a report and presentation

Dataset:-
The dataset contains 3,900 rows and 18 columns.

Key Features:-
Customer demographics — Age, Gender, Location
Product details — Item Purchased, Category, Size, Color
Purchase details — Purchase Amount, Season
Customer behavior — Previous Purchases, Frequency of Purchases
Marketing — Discount Applied, Promo Code Used
Customer feedback — Review Rating
Subscription — Subscription Status
Delivery — Shipping Type
Payment — Payment Method
Data Quality:-
Rows: 3,900
Columns: 18

3. Data Cleaning

The dataset was cleaned before performing SQL analysis.

Key Cleaning Activities
Checked for missing values
Handled missing review_rating values
Standardized column names using snake_case
Checked data types
Checked duplicate/inconsistent data
Verified discount and promo-code fields
Removed redundant columns where applicable

Example:
df.columns = df.columns.str.lower().str.replace(" ", "_")

Missing Value Treatment

Missing review ratings were replaced using the median rating of each product category.

7. Key Results & Insights

The analysis generated several useful business insights:

The dataset contains 3,900 customer transactions.
Male customers generated higher total revenue than female customers in the analyzed dataset.
Loyal customers represent the largest customer segment.
Non-subscribers account for a larger customer base and total revenue in this dataset.
Express shipping customers had a slightly higher average purchase amount than Standard shipping customers.
Several products showed high dependency on discounts.
Product ratings were generally concentrated around the 3.8–3.9 range.
SQL ranking helped identify high-performing products within individual categories.
Customer segmentation can help businesses develop targeted marketing strategies.
